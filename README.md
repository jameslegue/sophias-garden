# Sophia's Garden

An 8-bit tower-climbing game designed by Sophia. Built for phones (portrait).

Climb the tower one obby floor at a time - Rose, Carrot, Apple, Melon, Strawberry - and collect each fruit's seed with Rosie the poodle. At the top: **Battle vs Sophia**, where you give her every seed to make the garden bloom.

## How to play
- **◀ ▶** to move, **JUMP** to jump (keyboard: arrows / A D, Space or Up to jump)
- Touch a flower to save your spot. Hit a thorn and you go back to your last flower.
- Reach the seed at the top of each floor - Rosie grabs it for you.
- At the top, Sophia is mad! Keep moving to dodge her fruit. When she's dizzy, run to her and Rosie gives her a seed.
- **MY AVATAR** on the title screen to design your character (or hit RANDOM).

## Run it
No build step. Serve the folder and open it:

```
python3 -m http.server 8000
```

Then go to http://localhost:8000. (Opening `index.html` directly won't work - browsers block modules from `file://`.)

On a phone: host on GitHub Pages (repo Settings → Pages → deploy from branch), open the link, then "Add to Home Screen".

Testing shortcut: `?level=levels/level1/01-rose.json` jumps straight to a floor (`06-battle.json` for the boss).

Offline: `sw.js` caches the game so it works from the home screen with no signal. It always tries the network first, so updates show up right away. If you add new files, add them to the list in `sw.js` too (anything missed still gets cached the first time it loads).

## 3D version (`/3d`)
All of Level 1 in free-roaming, blocky (Minecraft-style) 3D, Roblox-obby style. Tap **3D!** on the 2D title screen.
- **Rose / Carrot / Apple / Melon / Strawberry Towers**: climb the platforms spiraling around each tower to the seed on the roof. Same tricks as the 2D floors: sinking carrots over thorns, falling apples, bouncy melons and slippery juice, vanishing strawberries.
- **Battle vs Sophia**: she's mad, throws fruit and cartwheels away. When she's dizzy, run to her and Rosie gives her a seed. Five seeds and her garden blooms.
- Phone: left side of the screen = joystick, right side = drag to look, JUMP button. Computer: WASD/arrows, Space, Q/E or drag to look.
- Fall off or touch thorns/apples and you go back to your last flower. 3D seeds are saved separately from the 2D game.

Built with [Three.js](https://threejs.org) (free, MIT license, copied into `vendor/` so it works offline). Levels are generated by `3d/levels/make-levels.py` into JSON files: a list of block boxes `[x, y, z, width, height, depth, type]` plus moving platforms and apple spots. Blocks: `grass`, `dirt`, `brick`, `vine`, `thorn`, `branch`, `leaves`, `melon`, `juice`, `seedstep`; moving: `carrot`, `berry`.

## How it's built
- Plain JavaScript modules + an HTML canvas at 144x256, scaled up in whole pixels so it stays crisp
- One 16-color palette (`src/engine/palette.js`); all art is text grids of palette letters (`src/sprites.js`, `src/avatar/parts.js`)
- **Floors are data:** `levels/level1/*.json` - a text map using the blocks in `src/blocks.js`:

| Char | Block |
|---|---|
| `#` | Tower brick (solid) |
| `=` | Grass (solid) |
| `%` | Dirt (solid) |
| `-` | Rose vine (jump up through it, stand on top) |
| `^` | Thorns (send you back to your flower) |
| `b` | Apple branch (jump up through it) |
| `m` | Bouncy melon (boing!) |
| `j` | Juice puddle (slippery) |
| `o` | Seed step (tiny, jump up through it) |
| `c` | Carrot - sinks while you stand on it |
| `v` | Strawberry - vanishes after you land, grows back |
| `a` | Apple that keeps dropping from here |
| `P` | Player start |
| `C` | Checkpoint flower |
| `S` | Seed (end of floor) |
| `D` | Door |

The later "make your own obby" builder will save floors in this same format.
